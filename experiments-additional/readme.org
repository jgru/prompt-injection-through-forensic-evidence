#+TITLE: Additional Explorative Experiments
#+OPTIONS: toc:0 num:nil

In this subdirectory we present additional experiments, not that they
do not exactly match the ones presented in the paper but provide
additional evidence on the threats on DF-aided workflows mediated
through prompt injections.

Each script runs inferences for a given model and attack. The generated texts (plus some test generations to control MCP availability)
are then stored in JSON files.

For each model-attack combination, we used different forensic images (up to 6 for Persuasion). They vary slightly; some of them are controls, some 
contain the planted notes described in the paper, and some contain variations of these notes. While everything is accessible and interesting, only a
handful of the JSON files contain results from the 3 experiments presented in the paper.
